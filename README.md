# أرسو · ARSO

موقع أرسو: دورة «أسرار Claude» من البداية إلى الاحتراف. لكل وحدة درس متحرك بتعليق صوتي، وشرح مكتوب، وتمرين، واختبار، مع مسارات تعليمية حسب هدف المتعلم، وشهادة إتمام باسم المتدرب عند إنهاء أي مسار. يُحفظ تقدّم المتعلم في متصفحه.

التعليق الصوتي يستخدم الأصوات العربية المثبتة في متصفح المتعلم (Web Speech API)، فتختلف جودته بين الأجهزة، ويتعطل زره إذا لم يتوفر صوت عربي.

بدون أي مكتبات، يحتاج Node.js فقط.

```bash
npm start   # http://localhost:3000
npm test
```

## الملفات

| الملف | المحتوى |
|---|---|
| `public/course-data.js` | نصوص الوحدات والتمارين والاختبارات والمكتبة والمصادر |
| `public/course-motion.js` | مشاهد الدروس المتحركة وملخصات المراجعة والمسارات |
| `public/app.js` | التنقل، وتشغيل الدروس المتحركة والتعليق الصوتي، والاختبارات، والشهادة، وحفظ التقدّم |
| `public/course.css` | التصميم |
| `public/sculpture.js` | مجسّم الشعار الثلاثي الأبعاد في الصفحة الرئيسية |

## الهوية

ألوان أرسو: أسود `#090909`، ورقي `#EEEAE0`، فضي `#BFC3C8`، ذهبي `#C6A76A`. الشعار في `public/assets/symbol.svg`.

## النشر على Railway

مشروع جديد ← **Deploy from GitHub repo** ← هذا المستودع، ثم **Settings ← Networking ← Generate Domain** بالمنفذ 3000. لا يحتاج Volume ولا متغيرات.
