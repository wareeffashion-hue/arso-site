# أرسو · ARSO

موقع أرسو: بيت برمجيات سعودي يبني أدوات لتجار سلة. يعرض **الثيم** و**عزو** والخدمات القادمة.

بدون أي مكتبات، يحتاج Node.js فقط.

```bash
npm start   # http://localhost:3000
npm test
```

## الإعدادات (متغيرات Railway)

كلها اختيارية، وتتغير بدون تعديل الكود:

| المتغير | الاستخدام |
|---|---|
| `AZWO_URL` | رابط عزو (الافتراضي `https://azwo-production.up.railway.app/`) |
| `THEME_URL` | رابط الثيم في متجر ثيمات سلة. بمجرد إضافته تتحول حالة الثيم إلى «متاح الآن» |
| `CONTACT_EMAIL` | بريد التواصل، يظهر زره في قسم التواصل |
| `CONTACT_WHATSAPP` | رقم واتساب بالصيغة الدولية مثل `966500000000` |
| `PUBLIC_..._URL` | روابط خدمات مستقبلية، مثل `PUBLIC_REPORTS_URL` |
| `PORT` | `3000` |

## الهوية

ألوان أرسو: أسود `#111111`، أبيض `#FFFFFF`، فضي `#BFC3C8`، ذهبي `#C6A76A`. الشعار في `public/img/arso-symbol.svg` ومضمّن في الصفحة كرمز واحد يُعاد استخدامه.

## النشر على Railway

مشروع جديد ← **Deploy from GitHub repo** ← هذا المستودع، ثم المتغيرات أعلاه، ثم **Settings ← Networking ← Generate Domain** بالمنفذ 3000. لا يحتاج Volume.
